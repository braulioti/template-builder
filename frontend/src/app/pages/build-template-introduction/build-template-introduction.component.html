Build your first template

The template is defined in a YAML file. In it you declare folders, files, variables, and prompts. Template Builder reads this file and generates the project structure in the current directory.

Every template project must specify the format version at the top of the YAML. This version must match the Template Builder version without the third number: for example, for Template Builder 0.1.0, use version: 0.1 in the file.

Example: folder and file

Create a file named hello.yaml with the content below. It defines a folder New Folder and a file Hello.txt inside it with the content Hello World.

version: 0.1

folders:
  - path: "New Folder"

files:
  - path: "New Folder/Hello.txt"
    content: "Hello World"

To generate the folder and file, run the following in a terminal, in the same directory as hello.yaml:

TemplateBuilder hello.yaml

Template Details (version 0.2 or later)

Template details are optional metadata fields displayed in the CLI right after the banner and before any builder operations (folders, files, prompts). They help users identify the template—project name, author, contact info, and language—without opening the YAML file. All fields are optional and are shown only when present at the root of the YAML.

Attributes

Name Required Description
name optional Project or template name.
author optional Author or maintainer name.
email optional Author email address.
url optional Author or project URL.
language optional Template or content language (e.g. pt-BR, en). The field idioma is also supported.
installParameter required (versions above 0.2) Parameter name used for repository installation (e.g. TemplateBuilder -r my-template). Required for templates with version greater than 0.2.

Example

Below is a template with version 0.2 and template details at the root. When you run the template, the CLI displays these details before creating folders and files.

version: 0.2

name: "My WordPress Theme"
author: "Jane Doe"
email: "jane@example.com"
url: "https://example.com"
language: "en"
installParameter: "my-wordpress-theme"

folders:
  - path: "assets"

files:
  - path: "style.css"
    content: "/* Theme: My WordPress Theme */"
