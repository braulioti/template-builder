TemplateBuilder Argument List

Reference for command-line arguments supported by the TemplateBuilder CLI. Usage: TemplateBuilder [options] <file.yaml>

-h, --help

Shows the help message and exits. Displays the list of available options, the usage syntax, and the URL used for the templates list (when using -l). Use this option when you need a quick reminder of how to run TemplateBuilder or which arguments are supported.

-i, --interactive

Forces interactive mode so that prompts defined in the template are shown and the user can enter values. This is useful when running TemplateBuilder from an IDE or from an environment where stdin is not attached to a terminal; in those cases, prompts are normally skipped and default or empty values are used. With -i, the program will wait for user input for each prompt.

-l, --list

Downloads the templates list from the configured URL (by default the TemplateBuilder repository), displays it in an interactive menu where you can move with the Up/Down arrow keys and press Enter to select an item. The selected line (the part before the semicolon in each list entry) is then printed to the console. Use this option to discover available templates or to get the identifier or URL of a template before running it. The list URL can be changed in config.ini in the same directory as the executable (section ARGUMENTS, key ListURL).

<file.yaml>

Path to the YAML template file to run. This is a positional argument: you pass the path to your .yaml file after any options. TemplateBuilder will read the file, resolve variables and prompts (if in interactive mode), and generate the folders and files defined in the template. The path can be relative to the current directory or absolute. If the file does not exist, the program reports an error and exits with a non-zero code.
